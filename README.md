# Customer Shopping Behavior Analysis

## Project Overview
An end-to-end data analytics project exploring customer shopping behavior to identify purchasing patterns, customer segments, and business insights using Python, SQL, and Power BI.

## Tools & Technologies
- **Python:** Data exploration and cleaning
- **SQL:** Customer behavior analysis and business queries
- **Power BI:** Interactive dashboards and data visualization

## Project Workflow
1. Import, explore, and clean the customer shopping dataset using Python.
2. Load the processed data into a SQL database.
3. Execute SQL queries to analyze customer segments, loyalty, and purchase behavior.
4. Build an interactive Power BI dashboard to visualize key trends and insights.
5. Summarize findings and business recommendations.

## Repository Contents
- `Customer_Shopping_Behavior_Analysis.ipynb` — Data exploration and cleaning
- `customer_behavior_sql_queries.sql` — SQL analysis queries
- `customer_behavior_dashboard.pbix` — Power BI dashboard
- `customer_shopping_behavior.csv` — Dataset
- `Business Problem Document.pdf` — Business problem definition

## Objective
Demonstrate an end-to-end analytics workflow that transforms raw customer data into meaningful insights for business decision-making.
